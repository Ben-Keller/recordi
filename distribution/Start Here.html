Recordi · Apple Silicon

Your meetings, saved locally.

Record microphone and computer audio together, then turn the recording into a plain text transcript. No account or cloud transcription service is needed.

1. Install Audio Hijack

Download Audio Hijack and place it in Applications. It is a separate app with its own license and audio permissions.

2. Double-click Set Up Recordi

Extract the entire ZIP, then double-click Set Up Recordi.command in this folder. A Terminal window shows progress; you do not need to type commands. Leave the window open until setup finishes.

Setup installs the app in your Applications folder, prepares the speech model, and checks transcription with a public sample. No Homebrew, developer tools, or local signing setup is needed.

Already have the model? Choose Use Existing File when asked. On your first Mac, use Finder → Go → Go to Folder to open ~/Library/Application Support/Recordi/models/, then copy ggml-large-v3-turbo.bin to the new Mac. You can also place it beside this guide before running setup. Otherwise choose Download (about 1.6 GB, once per Mac). Setup verifies the file and reuses an installed copy.

This personal release is not notarized. If macOS blocks the setup file or Recordi, follow Apple’s instructions: after attempting to open it, go to System Settings → Privacy & Security → Open Anyway. You may need to do this once for each. Keep the setup window open: after approving a blocked item, return to Terminal and press Return at the retry prompt to continue. Do not turn off Gatekeeper. macOS may also request permission for Terminal or Recordi to access Documents.

3. Connect your audio

  1. In Audio Hijack, enable Settings → Advanced → Allow execution of external scripts.
  2. Create exactly one session named Meeting Recorder.
  3. Connect the blocks as shown below. System audio goes to both the Output Device and Recorder. The microphone goes only to the Recorder. There is no Output Device → Recorder connection.
  4. Choose your microphone and listening device. Set the Recorder to MP3, 128 kbps stereo, with automatic date/time filenames and no automatic splitting.
  5. Set its save folder to ~/Documents/Recordi/recordings/ on this Mac. In a folder picker, press Command–Shift–G to enter that path. Setup creates the folder for you.

4. Enable the completion script

In Finder, use Go → Go to Folder to open ~/Library/Application Support/Recordi/commands/. Open Transcribe Finished Recording.js with TextEdit and copy its contents.

In Audio Hijack’s Window → Script Library, create a script named Transcribe Finished Recording and paste those contents. In Meeting Recorder → Scripting → New Automation, choose Recording Stop and run that script.

Use the script generated on this Mac: it contains your local app path. Recordi can also recover completed recordings by scanning the folder while idle, usually after about 30 seconds.

5. Try a short recording

Click Recordi’s recorder icon in the menu bar and choose Start Recording. Speak and play some computer audio, then choose Stop Recording. After transcription finishes, choose Open Latest Transcript to select the text file in Finder.

Open Recordi Folder shows recordings/, transcripts/, and logs/. The original audio stays intact. Audio Hijack only needs to run while recording. Enable Launch at Login from Recordi’s menu if you want it.

Updating or retrying

Download a new package and run Set Up Recordi.command again. It preserves your recordings and transcripts and reuses the model. If a download is interrupted, run setup again to resume. Setup is complete only after it reports Setup verified and confirms the Audio Hijack scripts are ready. If a step fails, resolve the displayed error and press Return to retry that step in the same window. A log is saved at ~/Library/Application Support/Recordi/setup.log.
